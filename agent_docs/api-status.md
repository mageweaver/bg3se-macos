# API Status (v0.43.0)

Full namespace-by-namespace parity status with Windows BG3SE.

Overall parity remains approximately 94.8% pending recomputation after Wave 7 live verification. The current figure comes from the [ROADMAP.md matrix](../ROADMAP.md#feature-parity-matrix) under behavioral accounting with per-function contract diffs against the Windows registration blocks (admitted fail-closed stubs score zero; macOS-only extras earn no credit; matched-upstream contracts leave the denominator). Every intentionally fail-closed API is cataloged in [docs/deferrals.md](../docs/deferrals.md).

- **Osi.*** - Dynamic metatable (40+ functions), **OsirisFunctionHandle encoding** (v0.36.39), crash-resilient dispatch with breadcrumbs
- **Ext.Osiris** - RegisterListener, NewCall/NewQuery/NewEvent (server context guards)
- **Context System** - Ext.IsServer/IsClient/GetContext, two-phase bootstrap (v0.36.4)
- **Ext.Entity** - GUID lookup, **1,999 components registered** (462 layouts: 169 verified + 293 generated), **1,730 sizes** (1,577 Ghidra + 153 Windows-only, 87% coverage), GetByHandle, **Dual EntityWorld Complete** (client + server auto-captured), **Entity Events** (Subscribe/OnCreate/OnDestroy + 8 variants, Unsubscribe — salted pool, deferred queue, per-entity hooks), **CreateComponent** (verified ComponentOps registry at EntityWorld+0x390, vptr slot 5), and archetype enumeration. **19/26 (73.1%)** of the Windows Entity.inl registration block is behavioral. Wave 7 A1 added **HandleToUuid, UuidToHandle, GetAllEntitiesWithUuid, GetRegisteredComponentTypes** (`mapped`/`oneFrame` filters), and **GetEntitiesAroundPosition** (Windows 2D XZ-circle behavior). Remaining gaps: Create, Destroy, OnSystemUpdate, OnSystemPostUpdate, GetTrace, ClearTrace, and the EnableTracing stub. B6 made the two system-update callbacks implementation-ready, but they remain gaps until the wrappers land.[^entity-stubs]
